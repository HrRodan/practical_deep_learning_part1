# Cat vs Dog Classifier

A minimal, beautiful Gradio web application for classifying Cat vs Dog images, trained using `fastai` and `resnet18` based on [02-saving-a-basic-fastai-model.ipynb](../../02-saving-a-basic-fastai-model.ipynb).

## Running Locally

```bash
uv run python chapter_02/gradio_app/app.py
```
